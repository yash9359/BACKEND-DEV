📘 EXPRESS MIDDLEWARE – NOTES
🔹 Middleware kya hota hai?

Middleware = function jo request aur response ke beech chalta hai

👉 Request aayi
👉 Middleware chala
👉 Phir route handler

📌 Middleware req, res ko access karta hai aur chahe to modify bhi kar sakta hai.

🔹 Middleware ka syntax
(req, res, next) => {
   // kaam
   next();
}

🔸 Parameters

req → incoming request

res → response object

next() → agle middleware / route pe bhejne ke liye

⚠️ next() nahi likha → request wahi freeze

🔹 Middleware kyun use hote hain?

Middleware use hote hain:

Body parse karne ke liye (req.body)

Authentication / Authorization

Logging (kisne kab hit kiya)

Request modify karne ke liye

Validation

Error handling

📌 Rule:

Route se pehle ka kaam = Middleware

🔹 Types of Middleware
1️⃣ Built-in Middleware

Express ke saath aate hain

app.use(express.urlencoded({ extended: false }));


👉 Form / POST data ko read karta hai
👉 req.body banata hai

❌ Agar na likho:

req.body === undefined


🧠 Analogy:

Packet hai, par kholne ka tool nahi

2️⃣ Custom Middleware

Hum khud banate hain

app.use((req, res, next) => {
   console.log("Hello from middleware");
   next();
});


📌 Ye har request pe chalega

3️⃣ Multiple Middleware (Chain)
app.use(middleware1);
app.use(middleware2);
app.use(route);


Flow:

middleware1 → middleware2 → route

🔹 next() ka role (IMPORTANT ⭐)
next(); // request ko aage bhejta hai

Agar next() nahi likha:

Request ruk jaayegi

Route kabhi call nahi hoga

Agar response bhej diya:
res.json({msg: "done"});


👉 Flow wahi end

🔹 Middleware request ko modify bhi kar sakta hai
req.userName = "Yash";
next();


Baad mein:

console.log(req.userName);


📌 Same request object poore flow me ghoomta hai

🔹 Logging Middleware (File example)
app.use((req, res, next) => {
   fs.appendFile(
     "log.txt",
     `\n${Date.now()} ${req.method} ${req.path}`,
     () => next()
   );
});


👉 Har request ka record ban jaata hai

🔹 Route-level Middleware

Sirf ek route ke liye

app.get("/users", middleware, (req, res) => {
   res.send("Users");
});

🔹 Middleware vs Route
Middleware	Route
Beech me chalta	End me response deta
next() hota	next() optional
Reusable	Specific
🔹 Common interview points ⭐

Middleware request-response cycle ka part hota hai

next() flow control karta hai

req.body middleware ke bina undefined hota hai

Order matters (top to bottom)

🔹 One-line definition (Interview)

Middleware is a function that executes between request and response to process, modify, or validate data before sending the final response.
