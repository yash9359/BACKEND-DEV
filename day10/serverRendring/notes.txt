
1️⃣ Form submit pe actually hota kya hai
Tera form 👇
<form method="POST" action="/url">
    <input type="text" name="url" placeholder="https://example.com">
    <button type="submit">Generate</button>
</form>

Important cheez:
👉 name="url"
Yehi naam backend ko batata hai:

bhai input ka key url hoga


2️⃣ Jab tu submit dabata hai
Browser POST request bhejta hai /url pe
Aur data aise jata hai (by default):
Content-Type: application/x-www-form-urlencoded

Body hoti hai 👇
url=https://example.com

⚠️ Ye JSON nahi hota, plain form data hota hai

3️⃣ Express ko samjh kaise aata hai ye data?
Ye wali line yaad kar 👇
app.use(express.urlencoded({ extended: false }));

Ye middleware kya karta hai?
👉 form data ko parse karke JS object bana deta hai
So this 👇
url=https://example.com

ban jata hai 👇
{
  url: "https://example.com"
}

Aur ye object aa jata hai:
req.body


4️⃣ Isliye controller me ye kaam karta hai
const body = req.body;

console.log(body);

Output 👇
{ url: 'https://example.com' }

Aur isliye ye bhi valid hai 👇
body.url


5️⃣ Flow ko ek line me samajh (🔥 exam + interview ready)
👉 HTML form
👉 browser sends url=https://example.com
👉 express.urlencoded() parses it
👉 Express banata hai JS object
👉 object milta hai req.body me

6️⃣ JSON kab banta hai?
Agar tu Postman / fetch / axios se bhejta:
fetch("/url", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    url: "https://example.com"
  })
});

Tab ye middleware chahiye hota 👇
app.use(express.json());


7️⃣ Short analogy (bonus 🧠)
🧾 Form = paper form
🖊️ name="url" = form ka column
📮 Submit = post office bhejna
📬 express.urlencoded = clerk jo form padh ke data register me likh deta
📘 req.body = register ka entry
