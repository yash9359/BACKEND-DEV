STEP 7️⃣ POST API (insert data)
app.post("/api/users", async (req, res) => {
  const { firstName, email, age } = req.body;

  if (!firstName || !email) {
    return res.status(400).json({ msg: "Required fields missing" });
  }

  const user = await User.create({
    firstName,
    email,
    age,
  });

  res.status(201).json(user);
});


🧠 Yahan Schema ka magic:

email duplicate → error

firstName missing → error

STEP 8️⃣ PATCH API (update)
app.patch("/api/users/:id", async (req, res) => {
  const updatedUser = await User.findByIdAndUpdate(
    req.params.id,
    req.body,
    { new: true, runValidators: true }
  );

  res.json(updatedUser);
});


🧠 Key concepts:

req.params.id → URL se ID

req.body → jo update karna

{ new: true } → updated data return

runValidators → schema rules apply

1️⃣0️⃣ async–await vs .then()

} catch (err) {
  res.status(500).json(err);
