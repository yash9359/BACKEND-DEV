🧩 Sabse pehle samjho: Node.js hota kya hai?

Node.js ek single-worker banda jaisa hota hai 👷‍♂️
👉 Ek time pe sirf ek hi kaam kar sakta hai

Agar usse bol do:

“Bhai file padh ke aa”

to do tareeke hote hain 👇

🔴 TAREEKA 1: readFileSync (Synchronous)
Code
const result = fs.readFileSync("./contacts.txt", "utf-8");
console.log(result);

Isme hota kya hai?

Node.js bolta hai:
“Jab tak file poori read nahi hoti, mai aage kuch nahi karunga”

File read hoti hai

Phir result sidha variable me aa jata hai

Real-life example 🧠

Tum mummy se bolte ho:

“Maa chai bana do”

Aur tum kitchen me khade ho ke wait karte ho ☕
jab tak chai nahi bani → kuch aur kaam nahi ❌

👉 Ye hi blocking hai

Matlab:

Simple hai

Lekin server ke liye kharab 👎
kyunki baki log wait karte rahenge

🟢 TAREEKA 2: readFile (Asynchronous)
Code
fs.readFile("./contacts.txt", "utf-8", (err, result) => {
    if (err) {
        console.log(err);
    } else {
        console.log(result);
    }
});

Ab dhyaan se sunna 👂

Isme Node.js kya bolta hai:

“File padhna time lega
mai abhi aur kaam karta hoon
jab file ready ho jaaye to mujhe bata dena”

📞 “Bata dena” = CALLBACK FUNCTION

❓ Callback kya hota hai?

Callback ek function hota hai jo baad me call hota hai

👉 Matlab:

“Ye kaam ho jaaye to ye function chala dena”

Isliye likhte ho:

(err, result) => { ... }

🧠 Real-life example (Async)

Tum mummy se bolte ho:

“Maa chai bana do,
ban jaaye to awaaz de dena”

Tum tab tak:

phone chala rahe ho 📱

code likh rahe ho 💻

Chai ready hui → mummy boli:

“Chai aa jao ☕”

👉 Ye hi callback hai

🔥 Sabse IMPORTANT baat (yahin log atakte hain)

❌ Ye GALAT soch:

const result = fs.readFile(...);


❌ Ye kaam kabhi nahi karega

Kyun?

Kyunki:

readFile return kuch karta hi nahi

result future me aata hai

Isliye result sirf callback ke andar milta hai

✔️ Sahi jagah:

fs.readFile(..., (err, result) => {
    console.log(result); // ✅ yahin milega
});

🧾 Short Summary (yaad rakhne ke liye)
readFileSync

Ruk ke kaam karta hai 🛑

Direct value deta hai

Server slow karta hai ❌

readFile

Ruke bina kaam karta hai 🚀

Callback deta hai

Server fast rakhta hai ✅

🧠 One-line golden rule 🌟

Backend / Node.js me hamesha async use karo,
sync sirf seekhne ya testing ke liye hota hai
